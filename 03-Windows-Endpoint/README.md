# Lab 03 - Windows Event Logging & Wazuh Detection

## Objective

Understand how Windows Security Events are generated and how Wazuh collects, analyzes, and presents those events for investigation.

---

# Lab Overview

This lab focused on understanding Windows Event Logs before relying on the SIEM.

Rather than immediately looking inside Wazuh, I first investigated the events directly in Windows Event Viewer and then correlated them with the alerts generated by Wazuh.

This helped reinforce the relationship between the endpoint, the Wazuh Agent, and the SIEM.

# Investigation Process

For every event I verified:

- Event ID
- Timestamp
- Computer Name
- User Account
- Target User
- Windows Event Viewer
- Wazuh Alert
- Rule ID

This confirmed that the endpoint telemetry matched the SIEM alert.

# Lessons Learned

One of the biggest lessons from this lab is that Wazuh does not create Windows security events.

Windows generates the event first.

The Wazuh Agent collects it.

The Wazuh Manager analyzes it.

The Indexer stores it.

Finally, the Dashboard allows analysts to investigate it.

Understanding the source of the data makes troubleshooting much easier than simply memorizing commands.

## What I Would Do Next

If this were a production SOC, I would:

- Investigate whether the activity was expected or malicious.
- Check for related events on the same endpoint.
- Review the originating account's recent activity.
- Determine whether additional containment or escalation was necessary.
