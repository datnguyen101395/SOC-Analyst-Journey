# 🛡️ SOC Analyst Journey

> Building an enterprise-style Security Operations Center from scratch while documenting every lesson, challenge, and success along the way.

---

## About This Project

This repository documents my transition from the U.S. Air Force into cybersecurity through hands-on, enterprise-style security projects.

Rather than relying solely on certifications or classroom theory, I'm building a long-term portfolio that demonstrates practical skills in Security Operations, Linux administration, Windows security, threat detection, and incident response.

I created this repository because I want to move beyond the theory I learned in school and gain practical experience by building real systems. My goal is to understand what Security Operations Center (SOC) analysts actually do on a day-to-day basis and recreate those responsibilities in a home lab that reflects real-world environments.

Rather than cramming as many tools as possible into a single lab, I am building this portfolio one project at a time. Every lab has a purpose, every challenge is documented, and every mistake becomes part of the learning process.

This repository is more than a collection of cybersecurity labs—it's a long-term record of my growth as I develop the technical skills, troubleshooting mindset, and documentation habits required to become a SOC Analyst.

---

# 🎯 Objectives

This project is designed to:

- Develop practical SOC analyst skills through hands-on labs.
- Build and operate an enterprise-style home lab.
- Learn Linux, Windows, networking, and security tooling.
- Simulate real-world attack and defense scenarios.
- Document every project with professional technical documentation.
- Demonstrate practical experience beyond certifications.
